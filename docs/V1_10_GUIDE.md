# Cardfolio v1.10 — 卡面与 FTF

本版只扩充卡面与账户 FTF 标注；v1.9 已有权益 / 年费回看功能保留，没有新增福利调查、提醒规则或私人数据分析。

## 使用方式

1. 在「我的信用卡」查看内置卡面；点击卡面可放大并查看来源与实际像素。
2. 信用卡的当前产品与发卡行用于匹配。目录支持本次 48 种产品及常见别名；未匹配产品保留「更换卡面」功能，不猜测相近卡种。
3. FTF 标签显示「无 FTF」「有 FTF · 费率」或待确认。点击标签查看标准条款、核实日期与账户判断依据。
4. BofA 若记录了免 FTF 原始卡转为收 FTF 产品，自动显示继承。历史缺失时：编辑该卡 → 外币交易手续费 / FTF → 已确认：BofA 转卡继承无 FTF → 保存。
5. 可手动选择使用标准条款、有 FTF、无 FTF或待确认。仅影响这一张账户，同名卡不合并。

账户手动标记会随 JSON 全量导出 / 导入。FTF 不参与奖励、报销或现金统计，不改变原始字段含义。数据仍为 v6，存储键不变；旧 JSON 无需新增字段即可导入。

## 更新

先导出 JSON。GitHub Pages 用本版 PWA ZIP 中的整套程序文件覆盖原文件，一次提交，保持原网址；联网检查更新并按提示重新打开。不要清除网站数据。独立离线使用下载本版 HTML；若更换文件路径后数据为空，手动导入先前 JSON。

本版 HTML 约 4.87 MiB；内置更多图片使第一次下载体积增大。离线和业务本地保存能力保留；不会联网获取个人记录。

## 实际覆盖与限制

48 种请求产品均可匹配；其中部分旧版 / 官方原图较小，不能保证每张都达到高清像素。实际像素与来源见 SOURCES_v1_10.md。卡面是产品示意，不保证与你手中实物的发行年份、材质或定制颜色相同；可从本机上传替换。

测试为 Windows Chromium 桌面和触屏视口模拟，未使用真实 iPhone Safari。需在真机复核字体、键盘、系统文件选择 / 分享，以及主屏幕 App 存储。来源与公开条款可能变化，不进行后台自动抓取或自动更新 FTF。

完整部署、iPhone 安装与迁移步骤见 README.md。既有 v1.9 权益功能说明保留在 V1_9_GUIDE.md。
